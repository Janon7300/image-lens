# Image Lens — Image Translator

ส่วนขยายโอเพนซอร์สสำหรับอ่านข้อความในรูปภาพบนหน้าเว็บ และแปลเป็นข้อความภาษาไทยหรืออังกฤษด้วย AI ที่คุณเลือก แสดงผลบนภาพหรือในแผง พร้อมสลับดูต้นฉบับและโหมดแปลเมื่อหยุดเลื่อน

**ใช้บนคอม ติดตั้งจากซอร์สได้ ไม่ต้อง build และต้องใช้ API key ของตนเอง** การแปลส่งภาพไปบริการออนไลน์ ไม่ใช่การประมวลผลออฟไลน์

## 1. ดาวน์โหลด

กด **Code → Download ZIP** แล้วแตกไฟล์ หรือใช้ Git:

```sh
git clone https://github.com/Janon7300/image-lens.git
cd image-lens
```

## 2. ติดตั้งบนคอม

### Chrome / Edge

1. เปิด `chrome://extensions` (Chrome) หรือ `edge://extensions` (Edge)
2. เปิด **Developer mode**
3. กด **Load unpacked** และเลือกโฟลเดอร์ `chromium` ที่มี `manifest.json` อยู่ข้างใน
4. เปิดเมนูส่วนขยาย แล้วเลือก **Image Lens**

เก็บโฟลเดอร์ที่โหลดไว้ในเครื่อง ไม่ย้ายหรือลบหลังติดตั้ง รุ่น Chromium กำหนดเบราว์เซอร์ขั้นต่ำ 116

### Firefox Desktop

1. เปิด `about:debugging#/runtime/this-firefox`
2. กด **Load Temporary Add-on**
3. เลือกไฟล์ `firefox/manifest.json`

ต้องใช้ Firefox 140 ขึ้นไป การติดตั้งจากซอร์สแบบนี้เป็น **ชั่วคราว** และต้องโหลดใหม่เมื่อปิดแล้วเปิด Firefox อีกครั้ง ชุดนี้ไม่ได้เป็นไฟล์ติดตั้งถาวรที่ Mozilla ลงนาม

## 3. ตั้งค่าผู้ให้บริการ AI

เปิด Image Lens → **ตั้งค่าบริการแปล / API key**

Endpoint คือ URL ปลายทางที่ส่วนขยายส่งคำขอแปล ต้องใส่ **URL เต็มที่ลงท้ายด้วย `/chat/completions`** ไม่ใช่แค่ base URL

| ช่อง | Gemini | OpenAI |
|---|---|---|
| API endpoint | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` | `https://api.openai.com/v1/chat/completions` |
| API key | คีย์ Gemini API ของคุณจาก Google AI Studio | คีย์ OpenAI API ของคุณจาก OpenAI Platform |
| โมเดล | เลือกโมเดล Gemini ที่รับภาพและใช้ผ่าน OpenAI-compatible API ได้ | เลือกโมเดลที่รับภาพและรองรับ Chat Completions |
| ภาษาปลายทาง | ไทย หรือ English | ไทย หรือ English |

### Gemini

1. ไปที่ [Google AI Studio](https://aistudio.google.com/api-keys) และจัดเตรียม API key ของตนเอง
2. ใส่ endpoint ของ Gemini ตามตาราง พร้อมคีย์
3. กด **ดึงรายชื่อโมเดลจากบริการ** และอนุญาตการเข้าถึงโดเมนบริการ
4. เลือกชื่อโมเดลที่บัญชีของคุณมีสิทธิใช้และรองรับภาพ
5. กด **ทดสอบโมเดลด้วยภาพตัวอย่าง** หากสำเร็จจะแสดงผลอ่านข้อความ HELLO

ใช้ชื่อโมเดลจากรายการของบริการ ไม่ต้องเดาชื่อ ไม่ใช่ชื่อแอป Gemini และไม่ใช่ URL ของเว็บไซต์แชต ส่วนขยายจัดการ prefix `models/` สำหรับ endpoint นี้ให้

### OpenAI

1. ไปที่ [OpenAI Platform](https://platform.openai.com/api-keys) และจัดเตรียม API key ของตนเอง
2. ใส่ endpoint ของ OpenAI ตามตาราง พร้อมคีย์
3. กดดึงรายชื่อโมเดล เลือกโมเดลที่รองรับ **image input และ Chat Completions** แล้วทดสอบภาพตัวอย่าง
4. ชื่อที่ปรากฏในรายการไม่ได้รับรองว่าทุกโมเดลรับภาพหรือบัญชีมีโควตา ต้องตรวจผลทดสอบและข้อมูลจากผู้ให้บริการ

### บันทึกและเริ่มใช้

1. เลือกภาษาปลายทาง อ่านรายละเอียดการส่งภาพ และติ๊กยินยอม
2. กด **บันทึกและอนุญาตบริการ**
3. เปิดหน้าเว็บ HTTP/HTTPS ที่มีภาพข้อความ
4. กด Image Lens → **เปิดตัวแปลในหน้านี้** → ปุ่มแปลหน้าจอ
5. เลือกแสดงกล่องบนภาพหรือข้อความในแผง และสลับดูต้นฉบับได้
6. หากต้องการ ให้เปิดแปลเมื่อหยุดเลื่อน ปิดโหมดนี้ได้ทุกเมื่อ

**การทดสอบและการแปลอาจใช้โควตาหรือมีค่าใช้จ่ายจากผู้ให้บริการ** ไม่มีคีย์กลางหรือเครดิตแถม ตรวจโควตาและราคากับผู้ให้บริการก่อนใช้

## แก้ปัญหาเบื้องต้น

| อาการ | สิ่งที่ควรตรวจ |
|---|---|
| HTTP 401 | API key ถูกต้องและยังใช้งานได้หรือไม่ |
| HTTP 403 | บัญชีมีสิทธิใช้โมเดล/บริการหรือไม่ |
| HTTP 404 | endpoint และชื่อโมเดลถูกต้องหรือไม่ |
| HTTP 429 | โควตา เครดิต หรืออัตราการส่งคำขอ |
| ทดสอบภาพไม่ผ่าน | โมเดลต้องรับภาพและรองรับรูปแบบ API ของส่วนขยาย |
| หมดเวลารอ | คำขอรอได้ประมาณ 25 วินาที ลองใหม่หรือเลือกโมเดลที่ตอบเร็วขึ้น |
| เปิดเครื่องมือไม่ได้ | ลองหน้า HTTP/HTTPS ปกติ หน้า settings และหน้าร้านส่วนขยายอาจถูกเบราว์เซอร์ป้องกัน |
| ต้องใส่คีย์ใหม่ | ปกติเก็บคีย์เฉพาะ session; Firefox มีตัวเลือกจำคีย์ในโปรไฟล์เครื่อง |

หลังอัปเดตซอร์ส ให้ Reload ส่วนขยายและรีเฟรชหน้าเว็บที่เปิดเครื่องมืออยู่

## ความเป็นส่วนตัว

เมื่อสั่งแปลหรือเปิดโหมดอัตโนมัติ **ภาพทั้งพื้นที่เว็บที่มองเห็น** จะส่งตรงไปผู้ให้บริการ AI ที่ตั้งค่า ไม่ได้ส่งเฉพาะตัวอักษร ภาพอาจมีข้อมูลส่วนตัวบนหน้าเว็บ จึงควรตรวจพื้นที่ก่อนแปล

- ไม่มีเซิร์ฟเวอร์ของผู้พัฒนารับภาพและไม่มี analytics
- API key ถูกส่งไป endpoint ที่เลือกเพื่อยืนยันตัวตน โมเดลและภาษาปลายทางถูกส่งพร้อมคำขอ
- เก็บค่าตั้งค่าและการยินยอมในโปรไฟล์เบราว์เซอร์ คีย์ปกติเก็บใน session
- Firefox มีตัวเลือกจำคีย์ในโปรไฟล์ซึ่งไม่ได้เข้ารหัสโดยส่วนขยาย และไม่ได้ซิงก์โดยส่วนขยาย กดลบคีย์จากหน้าตั้งค่าได้
- ไม่ตั้งใจบันทึกภาพลงดิสก์ ผลแปลอยู่ในหน่วยความจำของหน้าเว็บ
- เก็บผลแปลล่าสุดไม่เกิน 12,000 ตัวอักษร พร้อมชื่อโมเดล เวลา และเหตุผลจบคำตอบใน session เพื่อวินิจฉัยปัญหา ข้อความนี้อาจมีเนื้อหาจากหน้าเว็บ
- ปุ่มดึงโมเดลส่งคำขอยืนยันตัวตนไปบริการ ปุ่มทดสอบส่งภาพตัวอย่างที่สร้างในเครื่องและอาจใช้โควตา
- ผู้ให้บริการ AI จัดการข้อมูลตามนโยบายของตน การหยุดงานไม่สามารถเรียกคืนข้อมูลที่ส่งไปแล้ว

## ข้อจำกัดและสถานะทดสอบ

รุ่นทดลอง ภาษาในภาพที่อ่านได้ ความแม่นยำ และตำแหน่งข้อความขึ้นอยู่กับโมเดลและคุณภาพภาพ ภาษาปลายทางใน UI มีไทยและอังกฤษ ไม่รับรองทุกโมเดลหรือทุกเว็บ ไม่มีการลบข้อความเดิมหรือซ่อมพื้นหลังภาพ

ตรวจไวยากรณ์ JavaScript รูปแบบคำขอ/ผลตอบกลับ และการเชื่อมชื่อภายในแล้ว ยังไม่ได้ยืนยันคุณภาพการแปลกับ API จริงสำหรับชุดนี้ ไม่ได้ทดสอบกับอุปกรณ์ Android จริง
