◈ IMAGE LENS SETUP

เลือกตัวช่วยแปล
แล้วไปอ่านต่อได้เลย

ใช้บริการที่รองรับภาพและ API รูปแบบ OpenAI Chat Completions ผู้ใช้แต่ละคนใช้ key ของตนเอง

รายชื่อไม่ได้รับรองว่าโมเดลรับภาพหรือใช้ฟรี ต้องตรวจเงื่อนไขของบริการ ส่งภาพคำว่า HELLO ที่สร้างในเครื่อง ไม่ส่งภาพเว็บ การทดสอบใช้โควตา API ทดสอบข้อความตัวอย่างจากภาพ ด้วยโมเดลที่เลือก ใช้โควตาเพิ่ม 1 คำขอ

รายละเอียดผลแปลล่าสุด (เก็บเฉพาะ session)



กรองด้วยรายการคำหลังแปล ไม่เรียก AI เพิ่ม รายการยังไม่ครอบคลุมทุกคำและคำเลี่ยง รายละเอียดผลแปลล่าสุดยังเป็นข้อมูลดิบที่ไม่เซ็นเซอร์ ภาพต้นฉบับไม่ถูกแก้ไข

ภาพทั้งพื้นที่เว็บที่มองเห็นอาจมีชื่อบัญชีหรือข้อมูลอื่นปะปน บริการที่เลือกจะได้รับภาพและประมวลผลตามนโยบายของบริการนั้น ส่วนขยายไม่เก็บภาพลงดิสก์ ไม่มี analytics เก็บ API key ใน session หรือในโปรไฟล์เครื่องนี้เมื่อเลือกจำคีย์ (ไม่เข้ารหัสด้วย Keystore)




รุ่นทดลอง: ตำแหน่งคำแปลอาจคลาดเคลื่อน ไม่รองรับการลบข้อความเดิมหรือแปลล่วงหน้านอกหน้าจอ
